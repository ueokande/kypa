# Kypa

**Keep Your Policies Aligned**

Kypa is a planned OSS tool for scanning resource configuration against custom organizational policies, starting with GitHub Enterprise Cloud repositories.

Run scans centrally without installing workflows in each target repository. A PAT collects accessible files and settings; a static GitHub Pages dashboard presents the latest results with access controls configured separately.

**Status:** Kypa has not been implemented or published. The documentation describes proposed first-release interfaces, not available software. No OSS license has been selected.
